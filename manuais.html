Como conectar ao Google Sheets

  1. Publique cada aba como CSV: Arquivo > Compartilhar > Publicar na Web > formato CSV
  2. Copie a URL de cada publicação
  3. No código, substitua as constantes abaixo
  4. O site vai buscar via fetch automaticamente
SHEET_URL_FALHAS = ""
SHEET_URL_PARAMETROS = ""
SHEET_URL_ENTRADAS = ""

Publicar no GitHub Pages

  1. Crie um repositório: portal-manuais
  2. Envie este arquivo como index.html
  3. Vá em Settings → Pages → Deploy from branch → main / root
  4. Acesse: https://seu-usuario.github.io/portal-manuais

Dicas de uso

  • • Use a busca para filtrar em tempo real
  • • Toque no código/ID para copiar
  • • Filtre por máquina para diagnóstico rápido
  • • Mantenha o Google Sheets atualizado — o site reflete em segundos
